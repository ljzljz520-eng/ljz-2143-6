# VowDisplay：婚礼迎宾设计与安全分发工具

一个无第三方运行时依赖的 Node.js 20 全栈示例，覆盖 Web 设计、现场 C 端全屏窗口、活动/厅组/设备绑定、不可变版本、定时发布、离线缓存、授权撤销、现场截图校对、回退和保留清理。

## 启动

```bash
npm start
# 打开 http://localhost:8080/       管理/设计端
# 打开 http://localhost:8080/display 现场终端
npm test
```

数据默认写入 `./data`：

- `db.json`：活动、授权元数据、屏幕组、设备、版本、发布、屏幕截图校验和、操作凭据；
- `data/assets/`：照片/字体正文，活动结束或撤销后可被删除；
- 终端浏览器使用 IndexedDB 缓存完整资源包。

可用 `PORT` 与 `VOW_DATA_DIR` 覆盖端口和数据目录。生产环境应把本示例的简单 JSON 存储替换为带事务和备份的数据库，但领域规则可以复用。

## 现场操作流程

1. 在管理端创建活动（活动身份、新人姓名）。
2. 创建代表宴会厅的屏幕组；设备必须先绑定到活动和屏幕组。
3. 登记现场设备，取得一次性配对码；在 `/display?code=...` 输入/打开配对码换取设备令牌。
4. 上传照片和嵌入字体，填写来源、范围、截止时间等授权信息。
5. 编辑多语幻灯片、照片焦点、暗化层、字幕位置、颜色和安全边距。
6. 点击“运行嵌入字体/现场回退排版比对”，检查：
   - 长姓名自动缩放与换行；
   - 中日韩、拉丁、阿拉伯等多语混排；
   - `.notdef`/零宽缺字；
   - 字体嵌入与现场回退的字号、行数、字形、安全边距差异。
7. 资源齐备且排版报告通过后创建不可变版本。
8. 发布时必须选择一个厅组并明确勾选设备清单；可立即发布或定时发布。
9. 现场窗口按 `F` 全屏、`P` 上传截图、`H` 隐藏 HUD。
10. 管理端查看截图，必要时一键回退到上一可播放版本；没有可播放版本时使用无照片安全屏。

## 关键安全规则

### 活动与厅组隔离

设备令牌、轮询、素材下载和发布记录都同时绑定：

- `eventId`：活动身份；
- `groupId`：宴会厅/屏幕组；
- 明确的 `deviceIds`：发布设备清单。

发布接口拒绝其他活动或其他厅组的设备。终端轮询只查询自己的活动与厅组，素材 URL 还会再次验证该素材属于当前设备的当前发布，因此换厅或并行婚礼不会把另一对新人的照片推送到当前设备。

### 不可变版本与原子切换

照片焦点 X/Y、暗化层、字幕 X/Y、安全边距、多语文案和嵌入字体共同进入同一 payload，使用规范化 JSON 的 SHA-256 校验和生成版本。

版本创建前必须满足：

- 所有照片和字体均存在、属于本活动、授权有效且字节可读；
- 嵌入字体模式必须拥有字体资源；
- 排版报告的 checksum 与当前设计一致；
- 嵌入模式无缺字、溢出或安全边距违规；
- 嵌入/回退存在差异时必须人工确认。

终端下载每个素材后校验 SHA-256 与大小，并计算 release/version/asset manifest。所有字节和完整 payload 都写入 IndexedDB 后才提交并切换；旧版本在下载期间继续播放。资源缺失、校验失败或网络中断不会产生半版画面。

### 定时发布与断网

定时 release 未到时间保持 `scheduled`，终端继续收到旧版本；调度器到点才原子激活。断网终端继续播放已缓存的旧版本，管理页显示“未确认/心跳过期”，不会虚报设备已切换。设备重新联网后下载完整清单并校验 manifest，再切换。

### 照片授权撤销

撤销照片或字体会：

1. 将活动内引用该素材的待发布/定时发布标记为失败，禁止激活；
2. 将正在展示的发布标记为 `revoked`；
3. 立即创建同一活动、同一厅组、同一设备清单的回退发布；
4. 优先选择上一仍可播放版本，否则切换为不含照片的安全屏。

### 截图校对与回退

现场端上传 PNG 截图，服务器保存图片、SHA-256、设备、发布和时间作为校对凭据。管理端可依据截图回退。回退目标必须属于同一活动和厅组，且其引用资源仍授权、可读。

### 保留与擦除证明

活动结束的清理接口会删除服务器上的照片/字体/截图正文，保留：

- 操作日志；
- 授权来源/范围等元数据；
- 版本 SHA-256、资源清单和发布时间；
- 设备擦除证明；
- 不含照片正文的审计凭据。

终端收到 purge 指令后只删除本机可证明范围内的素材和发布缓存，并回传：

- 擦除前 manifest hash；
- 已删除 asset ID 清单；
- 保留项（操作凭据）；
- 终端确认时间。

离线终端在管理页仅显示“待擦除/等待终端确认”，不会被标记为已擦除。

## 代码结构

- `server/index.js`：HTTP API、认证、发布调度、设备轮询、素材下载、截图和清理；
- `server/domain.js`：payload 规范化、校验和、资源门禁、字体报告验证、厅组设备校验、回退规则；
- `server/store.js`：原子 JSON 存储（示例持久层）；
- `public/admin.html` / `admin.js`：设计、授权、排期、设备清单、校对与审计界面；
- `public/display.html` / `display.js`：现场全屏 C 端、IndexedDB 缓存、离线轮询、截图与擦除回执；
- `public/render-core.js`：浏览器预览和现场端共享的字体加载、换行、字形、安全边距与 canvas 渲染逻辑；
- `test/`：领域规则与端到端 API 验收测试。

## 验收测试覆盖

`npm test` 包含 11 项测试，覆盖资源不齐拒绝、版本不可变、跨厅误推拦截、明确设备清单、终端只下载本厅授权字节、定时到点切换、截图与回退、照片授权撤销后的安全屏，以及离线终端清理不得虚报等场景。
