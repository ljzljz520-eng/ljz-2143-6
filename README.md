# 婚礼迎宾设计与分发工具

一个面向多会场婚礼的可审计迎宾屏系统：

- Web 管理台编辑照片、照片焦点、暗化层、多语言姓名/宴会厅/字幕。
- C 现场窗口全屏轮播，使用设备令牌、活动身份和版本清单隔离不同新人。
- 后端 SQLite 保存素材授权、排期、屏幕组、屏幕版本、擦除任务和操作凭据。
- 发布版本必须有明确设备清单，照片/字体授权有效，且所有资源可完整校验。
- 终端只在资源下载齐全、SHA-256 校验通过、活动身份匹配后原子切换。
- 现场端自动上传带安全边距的合成校对图，也支持真实屏幕截图上传、审核和版本回退。
- 换厅先擦除旧活动缓存并回传证明；离线终端在管理页只显示“待确认”，不虚报已擦除。
- 撤销照片授权会阻止未激活版本；已激活设备重新连到命令后切换安全屏/旧安全版本并删除相关缓存。
- 活动结束按保留天数清理照片与截图字节，保留授权元数据、哈希和不含照片正文的审计凭据。

## 启动

```bash
npm install
ADMIN_TOKEN='change-me' npm start
```

默认地址：

- 管理台：<http://localhost:3000/>
- C 现场窗口：<http://localhost:3000/display.html>
- 默认开发管理令牌：`dev-admin-token`（生产必须用 `ADMIN_TOKEN` 覆盖）

## 关键安全语义

1. **活动身份锁**：素材 URL 必须携带属于该设备的版本 ID；版本事件、设备事件和待绑定状态全部校验。
2. **换厅门**：设备从 A 活动换到 B 活动时先收到 `wipe/event`，只有设备删除本地 IndexedDB 并提交擦除证明哈希后才提升到 B 活动。
3. **无半版切换**：终端激活时必须提交清单中全部 SHA-256、`hashVerified=true` 与正确 eventId。
4. **定时发布断网/撤销**：终端可预载，但到点命令由服务端再次校验授权；撤销或过期时发送安全屏命令，拒绝激活。
5. **可证明删除**：`delete_tasks` 只有 `pending/acked/deleted/failed`；没有终端 proof hash 永远不会显示为已删除。
6. **字体策略**：嵌入字体随清单分发和校验；管理台比较嵌入字体与本地回退栈的文本宽度、换行行数、字形覆盖和安全边距。真实现场排版仍以 C 端截图校对为准。

## 验收脚本

仓库当前包含一个端到端 API 验收脚本，可在服务器启动后执行：

```bash
bash /tmp/integration.sh
```

脚本覆盖：长名字/多语设计、授权上传、发布、素材哈希、半版拒绝、换厅擦除门、跨活动素材拒绝、定时版本遇到授权撤销以及截图证明接口。

## 数据与缓存

- 数据库：`data/wedding.db`
- 原始素材：`data/uploads/<event>/<sha256>`
- 截图：`data/uploads/<event>/proofs/<sha256>`
- 现场端缓存：浏览器 IndexedDB `wedding-display-v1`

清理只移除照片/截图/字体字节，数据库保留素材文件名、SHA-256、授权方、授权版本、撤销/清理时间和审计记录。
